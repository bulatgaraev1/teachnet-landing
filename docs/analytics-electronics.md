# Аналитика страницы /electronics

Счётчик Яндекс.Метрики: **96429194** (тот же, что на всём сайте, подключён в `<head>` страницы).
Параметры счётчика не менялись: `webvisor: true`, `clickmap: true`, `trackLinks: true`,
`accurateTrackBounce: true`, а также `referrer` и `url` текущей страницы.

Все цели (18) отправляются через одну обёртку `track(goal, params)` в `src/electronics/analytics.ts`.
Если Метрика не загрузилась или заблокирована, обёртка молча ничего не делает, страница работает.

## Параметры визита

При загрузке страницы: `ym(96429194, 'params', { direction: 'electronics' })`.
В отчётах: «Параметры визитов» → `direction`.

## Цели

Во всех строках тип цели в интерфейсе Метрики: **JavaScript-событие**, идентификатор цели указан в колонке ID.
Каждая цель отправляется один раз на действие, без дублей.

| ID | Тип | Когда срабатывает | Параметры |
|---|---|---|---|
| `cta_hero` | JavaScript-событие | клик по кнопке записи в первом экране (кнопка 1) | `block: "hero"` |
| `cta_trial` | JavaScript-событие | клик по кнопке записи в блоке пробного урока (кнопка 2) | `block: "trial"` |
| `cta_price` | JavaScript-событие | клик по кнопке записи в блоке цены (кнопка 3) | `block: "price"` |
| `cta_final` | JavaScript-событие | клик по кнопке записи в блоке контактов (кнопка 4) | `block: "final"` |
| `cta_menu` | JavaScript-событие | клик по кнопке записи в бургер-меню (мобильная версия) | `block: "menu"` |
| `msg_telegram` | JavaScript-событие | клик «Telegram» в окне записи | `from_block`: hero / trial / price / final / menu |
| `msg_vk` | JavaScript-событие | клик «VK» в окне записи | `from_block` |
| `msg_max` | JavaScript-событие | клик «MAX» в окне записи | `from_block` |
| `phone_click` | JavaScript-событие | любой клик по ссылке `tel:` на странице | `place`: modal / faq / contacts / header / menu / footer |
| `modal_close_empty` | JavaScript-событие | окно записи закрыто без выбора (крестик, Escape, клик вне окна) | `from_block` |
| `press_click` | JavaScript-событие | клик по карточке публикации в блоке «Нам доверяют» | `source`: minmol / monrt / kai / tatarinform |
| `map_click` | JavaScript-событие | клик «Открыть в Яндекс.Картах» | нет |
| `back_click` | JavaScript-событие | клик по кнопке «Назад» / «Все направления» | `mode`: history (вернулись назад) / directions (ссылка на блок направлений) |
| `cross_robotics` | JavaScript-событие | клик «Ребёнку 5–8 лет? Смотрите робототехнику →» | нет |
| `scroll_trial` | JavaScript-событие | блок `#trial` виден на 50% | нет |
| `scroll_price` | JavaScript-событие | блок `#price` виден на 50% | нет |
| `scroll_faq` | JavaScript-событие | блок `#faq` виден на 50% | нет |
| `scroll_contacts` | JavaScript-событие | блок `#contacts` виден на 50% | нет |

Пояснения:

- `from_block` показывает, какая кнопка открыла окно: hero / trial / price / final / menu.
- Скролл-цели срабатывают один раз за визит (вкладку). «Виден на 50%»: в окне не меньше
  половины блока, а для блоков выше экрана блок закрывает не меньше половины окна.
  Блок должен оставаться видимым 600 мс подряд (как у скролл-целей главной), чтобы
  не засчитывать пролёт через блок при переходе по якорю.
- `phone_click` из окна записи отправляется с `place: "modal"` и не дублируется целью `msg_*`.
  Кроме мест из задания, телефон есть в шапке и подвале: там `place` равен header и footer.

## Составная цель (рекомендуется)

**`lead_click`**: тип «Составная цель» не подходит (она про последовательность шагов),
поэтому создайте цель типа **JavaScript-событие** с условием «идентификатор цели»
и четырьмя условиями через «или» (в интерфейсе: «Добавить условие»):

- `msg_telegram`
- `msg_vk`
- `msg_max`
- `phone_click`

Так получится одна цель «контакт с нами» для отчётов и для оптимизации в Директе.

## Код источника в ссылках мессенджеров

Код источника визита добавляется к ссылке VK в окне записи:
`https://vk.me/teachnetru?ref=electronics_<код>`. Ссылки Telegram (`https://t.me/teachnet_school`)
и MAX (`https://max.ru/id165505564947_biz`) ведут в чат/профиль, параметр к ним не добавляется
(`param: null` в конфиге). Значение только из `A-Z a-z 0-9 _ -`, не длиннее 64 символов.

| Код | Источник | Правило |
|---|---|---|
| `yd` | Яндекс.Директ | `utm_source` = yandex / yandex_direct / ydirect / direct или в адресе есть `yclid` |
| `vk` | реклама VK | `utm_source` = vk / vkads / vk_ads / vkontakte / mytarget |
| `org` | поиск без меток | меток нет, referrer: Яндекс, ya.ru, Google, Bing, Mail.ru, DuckDuckGo, Yahoo, Rambler |
| `ref` | переход с другого сайта | меток нет, referrer: любой другой внешний сайт; а также любые другие utm-метки |
| `dir` | прямой заход | ни меток, ни внешнего referrer |

Таблица и списки редактируются в `src/content/electronics.config.ts` (`sourceCodes`).

Метки `utm_source`, `utm_medium`, `utm_campaign` и `yclid`, а также внешний referrer сохраняются
в `sessionStorage` (ключ `tn_visit`) на первой странице визита, любой странице сайта
(`src/lib/visit.ts`), и переносятся между страницами в рамках визита.

## Как проверить

1. Откройте `https://teachnet.ru/electronics?_ym_debug=1`, консоль браузера (F12).
2. Кликайте по элементам из таблицы: в консоли Метрика печатает `Reach goal. Counter: 96429194. Goal id: …`
   с параметрами.
3. Проверка кода источника: откройте страницу с `?utm_source=yandex&utm_medium=cpc`,
   откройте окно записи и наведите на VK: ссылка должна заканчиваться на `ref=electronics_yd`.

## Форма заявки в окне записи

В окне записи первой идёт форма (имя, телефон, возраст 10–11 / 12–13 / 14–15, согласие),
тот же компонент и тот же `send.php`, что на главной, со скрытым полем `source=electronics`.
Цель `lead_form` (уже существующая) отправляется только при успешном ответе сервера.
После успешной заявки закрытие окна не считается `modal_close_empty`.
